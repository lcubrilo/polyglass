# Code of conduct

Polyglass is about understanding each other across languages, and that's the spirit we want around it.

- Be kind and assume good intent. People here come from many countries, languages and levels of experience.
- Critique ideas and code, not people.
- No harassment, insults, discrimination or unwelcome personal attention, in any space connected to the
  project (issues, pull requests, discussions, chats).

If someone behaves in a way that breaks these rules, contact the maintainer privately through the
repository's Security tab or the contact on the maintainer's GitHub profile. Reports are handled
confidentially. The maintainer may remove comments, lock threads or block people who don't follow this
code.

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/), which is a good
reference for anything it doesn't cover.
